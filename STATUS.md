## How to actually test the UI (when you're ready)

1. `cd apps/api && npm run start:dev` — set `ADMIN_PHONES=<your real phone>` in `apps/api/.env` first if you want to log in as an admin and see `/admin`.
2. `cd apps/web && npm run dev` (or `npx next dev -p 3100`), open `http://localhost:3100` in a browser.
3. `cd apps/mobile && npx expo start` — scan the QR with Expo Go, or press `a`/`i` for an emulator if you have Android Studio/Xcode set up. **If using an Android Emulator (not a physical device)**, `apps/mobile/.env.development`'s `EXPO_PUBLIC_API_URL` needs to be `http://10.0.2.2:3000`, not `localhost` — the emulator can't resolve `localhost` to your host machine. A physical device over Expo Go needs your machine's real LAN IP instead. Env var changes need a full Expo restart (`Ctrl+C` then `npm run start`, or `npx expo start -c` if a stale Metro cache seems to be serving an old value), not just an in-app reload.
4. Report back anything broken (layout, a button that doesn't do what it should, a form that doesn't submit) and it'll get fixed.
