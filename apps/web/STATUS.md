## Homepage fix: "the web shows the old website"

## Bug fixed this pass: Next.js dev-server crash in `tailwind.config.ts`

Hit live while restarting the dev server mid-session: `next dev` intermittently crashed with `ReferenceError: require is not defined` while compiling the `/` route, because `tailwind.config.ts` called the bare CJS `require("../../design-tokens")` at module scope — Next's dev-server config loader apparently doesn't deterministically choose CJS vs. ESM interpretation for a `.ts` config file in this monorepo layout, and `require` is only a global in the CJS case. Fixed by switching to a proper ESM `import tokensImport from "../../design-tokens"` (works correctly under either interpretation given `esModuleInterop`), plus a new co-located `../../design-tokens.d.ts` ambient type declaration so `tsc` (which has `allowJs: false`) can still type the import without needing to compile the `.js` file itself. `design-tokens.js` itself is untouched — `apps/mobile`'s plain-JS `tailwind.config.js` still `require()`s it directly with no issue, since Metro's bundler is unambiguously CJS. Confirmed fixed: several clean dev-server restarts afterward, no recurrence.

## Known gaps in what's built

- **Editing a listing's photos still isn't built** — content-field editing shipped 2026-08-19 (`/listing/[id]/edit`), but photos are excluded on purpose: `apps/api`'s update endpoint doesn't touch `images` at all, only settable at create time.
